# GACHINO — интерактивное гачи-казино (демоверсия)

Настоящий запускаемый full-stack веб-проект, не скриншот. Интерфейс на русском, адаптивная верстка, 12 гачи-тематических слотов, собственный игровой движок и Node.js API.

## Как запустить

**Требуется Node.js 20 или новее.** Никаких пакетов npm устанавливать не нужно.

```bash
cd Gachino
npm start
```

Откройте **http://127.0.0.1:3000** в браузере. Для другого порта:

```bash
PORT=8080 npm start
```

Для доступа по сети: `HOST=0.0.0.0 PORT=3000 npm start` — только за настроенным HTTPS-прокси и с правильно ограниченным сетевым доступом. Для secure cookies задайте `SECURE_COOKIES=1` при HTTPS.

## Что работает

- Каталог из 12 игр: Iron Fortune, Locker Room Luck, Barbell Bonanza, Protein Rush, Ring of Power, Leather Legend, Dungeon Spin, Flex Empire, Shaker Storm, Crown of Gains, Gym Glory, Giga Jackpot.
- Слот-механика 5×3, 20 фиксированных линий, WILD, SCATTER, бесплатные спины, призовой фонд виртуального джекпота.
- Защищённая от подмены клиентом генерация случайных результатов **на сервере** (`crypto.randomInt`). Валидация ставок 20–1000 GC, шаг 20.
- Регистрация/вход, пароль на `scrypt` с солью, гостевые аккаунты, httpOnly cookie-сессии, журнал ставок и балансов, сохранение данных на диске.
- Начальный баланс 5 000 GC, ежедневная награда 500 GC, промокод `GACHINO` на 750 GC (один раз), выполнение миссий.
- История операций, виртуальный рейтинг игроков, VIP-уровни, избранное, поиск игр, фильтры, звуковые сигналы.
- Лимит дневных ставок, добровольная блокировка игры на 1/24/168 часов.
- Проверки ставок и операций на сервере, ограничения частоты запросов, заголовки безопасности.

## Структура

- `server.js` — HTTP-сервер и игровые API.
- `src/engine.js` — игровая математика и 12 игровых конфигураций.
- `src/store.js` — постоянное хранилище и журнал операций.
- `public/index.html` — интерфейс казино.
- `public/styles.css` — адаптивный дизайн.
- `public/app.js` — интерактивность и связь с API.
- `public/assets/` — изображения и иконки.
- `tests/` — тесты игрового движка и API.

Данные пользователей записываются в `data/casino.json`; папка создаётся автоматически. Для чистой демоверсии остановите сервер и удалите `data/casino.json`.

## Важно: только симуляция

**Gachino не является лицензированным оператором азартных игр.** GC — только виртуальные игровые кредиты, которые нельзя купить или обменять на реальные деньги. Реальных депозитов, банковских карт, криптовалютных операций, выплат и денежных джекпотов здесь нет. Баннеры и суммы GC — вымышленные игровые награды. Нельзя выдавать эту сборку за готовый к эксплуатации операторский сайт азартных игр.

Для реального коммерческого игорного сервиса потребовались бы отдельные юридическая проверка и лицензирование, KYC/AML, возрастная верификация, сертифицированный RNG/математика игр, ответственные игровые механизмы, защищённая платёжная инфраструктура, журналы аудита и production-хранилище с транзакционными гарантиями. Текущее JSON-хранилище предназначено для локальной демонстрации или небольшого внутреннего прототипа, не для высоконагруженной публичной эксплуатации.
