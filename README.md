# Gachino — версия для GitHub Pages

Рабочий статический демопроект гачи-казино с 12 тематическими слотами. Никакого Node.js, сервера или сборки для размещения на GitHub Pages не требуется.

## Как опубликовать

1. Создайте **публичный репозиторий** GitHub, например `gachino`. (В зависимости от тарифа можно использовать и приватный.)
2. Загрузите **содержимое этой папки в корень репозитория**: `index.html`, `app.js`, `demo-api.js`, `engine.js`, `styles.css`, `.nojekyll` и каталог `assets/`. Не помещайте файлы в дополнительную вложенную папку.
3. Перейдите в **Settings → Pages → Build and deployment**.
4. В разделе **Source** выберите **Deploy from a branch**, затем **main** и **/(root)**. Сохраните.
5. После публикации адрес обычно выглядит как `https://USERNAME.github.io/gachino/`. Если репозиторий называется `USERNAME.github.io`, главная страница будет по адресу `https://USERNAME.github.io/`.

Все пути к файлам относительные (`./assets/...`), поэтому проект работает и в корне домена, и в подкаталоге репозитория.

## Что работает

- 12 оригинальных гачи-слотов: 5 барабанов, 3 ряда, 20 линий выплат.
- Символы WILD, SCATTER, free spins, джекпот.
- Баланс виртуальных кредитов (стартовые 5 000 GC), ставки 20–1 000 GC, история.
- Локальные игровые профили, избранное, статистика.
- Бонус раз в 24 часа, промокод `GACHINO`, миссии.
- Локальная таблица лидеров и VIP-прогресс.
- Лимиты виртуальных ставок и добровольные перерывы.
- Адаптивный интерфейс и отключаемый звук.

## ВАЖНО: отличие от серверной версии

**Это демоигра на виртуальных кредитах. Никаких реальных денежных ставок, платежей или выводов нет.**

- GitHub Pages предоставляет **статический хостинг** и не запускает Node.js или базу данных на сервере.
- Все игровые результаты и начисления рассчитываются **в браузере пользователя**, поэтому их нельзя считать защищёнными от изменений или пригодными для реальной игровой экономики.
- Профили **не являются настоящими аккаунтами**: паролей нет. Имя только выбирает локальный профиль в текущем браузере.
- Данные и локальный рейтинг хранятся в `localStorage` **на текущем устройстве и в конкретном браузере**. Данные не синхронизируются между пользователями или устройствами и могут исчезнуть при очистке данных сайта.
- Отображение игрового результата никак не связано с реальными деньгами и не гарантирует проверенную коммерческую RTP/сертифицированную случайность.
- Для защищённых аккаунтов, общего рейтинга и тем более работы с денежными операциями требуется отдельный сервер и дополнительные юридические, платёжные и защитные механизмы.

## Файлы

- `index.html` — сайт.
- `styles.css` — оформление.
- `app.js` — интерфейс и анимации.
- `engine.js` — генерация сетки слотов и расчёт выигрышных линий.
- `demo-api.js` — имитация игрового API и сохранение данных в `localStorage`.
- `assets/` — изображения и фавикон.
- `.nojekyll` — отключение обработки сайта через Jekyll на GitHub Pages.

## Локальный запуск

Достаточно открыть `index.html` в браузере. Для корректной имитации GitHub Pages можно использовать `python3 -m http.server 8000` в папке проекта, а затем открыть `http://localhost:8000/`.
